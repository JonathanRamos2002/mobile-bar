# Mobile Bartending Website — Project Brief

## 1. Project Overview

Build a modern, visually appealing website for a mobile bartending business operated by two partners.

The business name is currently being explored, with three leading candidates:

- **Redline Social**
- **Midnight Pour**
- **Entre Copas**

Keep the branding flexible enough that the final business name can be swapped without redesigning the entire website.

The business provides mobile bartending services for:
- Weddings
- Private parties
- Birthdays and celebrations
- Corporate events
- Special occasions and private gatherings

The website's primary purpose is to showcase the service, establish credibility, communicate the brand's personality, and generate booking inquiries.

## 2. Brand Identity & Direction

### Overall Personality

The brand should combine:

- Professional and sophisticated hospitality.
- Playful, approachable personality.
- Modern, memorable branding.
- A welcoming atmosphere suitable for all types of clients.

The two business partners share an interest in JDM automotive culture. This can influence subtle branding details, naming, typography, and graphic elements.

Avoid making the website look like an automotive business, racing team, nightclub, or overly themed cocktail bar.

The automotive influence should be understated and recognizable primarily through design details rather than dominating the identity.

### Design Inspiration

Explore a combination of:
- Modern botanical aesthetics.
- Boutique cocktail lounges.
- Upscale hospitality websites.
- Minimalist Japanese-inspired design.
- Editorial photography and clean typography.

Avoid generic bartending website designs, excessive gradients, overly flashy animations, and stereotypical black-and-gold luxury styling.

## 3. Color Palette

The color palette is inspired by the actual mobile bar setup.

The physical bar cart is white with Aspen Valley green (#687F7A), and the wooden countertop is finished with Varathane Golden Oak stain.

Use these colors consistently throughout the website.

```css
:root {
  --color-primary: #687F7A;
  --color-primary-dark: #354540;

  --color-background: #F7F5EF;
  --color-white: #FFFFFF;

  --color-golden-oak: #C49A62;
  --color-terracotta: #B97860;

  --color-text: #303633;
  --color-muted: #777F79;
}
```

### Color Usage

- **Aspen Valley:** Primary brand color. Buttons, accents, navigation details, and interactive elements.
- **Deep Forest:** Dark sections, footer, headings, and hover states.
- **Warm Ivory:** Main website background.
- **White:** Cards, content areas, and clean backgrounds.
- **Golden Oak:** Warm decorative accents inspired by the wooden bar countertop.
- **Terracotta:** Occasional accent for small visual details.
- **Dark Charcoal:** Primary body text.
- **Muted Gray-Green:** Secondary text and supporting information.

Keep the overall website light, warm, and sophisticated. Avoid using all colors equally.

## 4. Website Structure

Build the website with the following sections:

### Homepage / Hero
- Strong, full-width photography.
- Clear business name and brand identity.
- Short, memorable headline.
- Brief description of the mobile bartending service.
- Prominent "Request a Quote" or "Book Your Event" button.

### About Us
- Introduce the two business partners.
- Explain the story behind the business.
- Highlight the passion for cocktails, hospitality, and creating memorable experiences.

### Services
Showcase the types of events served:
- Weddings
- Private parties
- Corporate events
- Birthdays and celebrations
- Custom events

### Packages
Provide an attractive layout for bartending packages.
Allow flexibility for future pricing, package descriptions, and customization options.

### Gallery
- Showcase the physical mobile bar.
- Cocktail photography.
- Event setups.
- Bartending and service experiences.

### Testimonials
Create a section for future client reviews and testimonials.

### Contact / Booking
Create a straightforward inquiry form that collects:
- Name
- Email
- Phone number
- Event date
- Event location
- Event type
- Estimated guest count
- Additional details

Include a clear call to action encouraging visitors to request a quote.

## 5. UI / UX Guidelines

- Fully responsive across desktop, tablet, and mobile.
- Prioritize mobile usability.
- Clean navigation and intuitive page structure.
- Consistent spacing and typography.
- Smooth, subtle transitions and hover effects.
- Strong photography and visual storytelling.
- Clear calls to action throughout the website.
- Accessible color contrast and readable typography.
- Fast loading and optimized images.

Use a sophisticated serif font for major headings paired with a clean sans-serif font for body text.

## 6. Development Guidelines

- First inspect the existing project structure and template before making changes.
- Preserve the existing framework and dependencies unless there is a compelling reason to change them.
- Use reusable components and maintainable code.
- Store brand colors as CSS variables.
- Keep content, branding, and components easy to update.
- Avoid unnecessary dependencies.
- Ensure all navigation links and interactive elements function correctly.
- Do not invent testimonials, client reviews, or business credentials.
- Use placeholder photography only where actual business photography is unavailable.
- Keep the business name configurable until a final name is selected.

## 7. Primary Objective

Create a polished, distinctive mobile bartending website that feels like a legitimate hospitality brand rather than a generic service-business template.

The finished website should communicate:

**Professional service. Great cocktails. Memorable experiences.**

It should make potential customers feel comfortable trusting the business with their weddings, celebrations, and special events.

The design should be distinctive enough to be memorable while remaining timeless and flexible as the business grows.
